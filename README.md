# 💻 C# Programming

### Object-Oriented Programming & Application Development

A collection of C# programming exercises, practical assignments (TDs/TPs), and applications developed during my engineering studies at **Polytech Angers – Automated Systems and Computer Engineering (SAGI)**.

This repository showcases my experience with object-oriented programming, data structures, software design, and graphical application development using C# and .NET.

## 📂 Projects & Exercises

### 🧩 Object-Oriented Programming
- Implementation of classes, objects, constructors, and properties.
- Encapsulation, inheritance, polymorphism, and interfaces.
- Abstract classes and method overriding.
- Operator overloading and indexers.

### 📊 Data Structures & Collections
- Arrays, lists, and generic collections.
- Object management and data manipulation.
- Iteration, searching, and collection operations.

### 🖥️ Windows Forms Applications
- Development of desktop applications using Windows Forms.
- Graphical interfaces and event-driven programming.
- User interactions, controls, and data binding.
- Integration of object-oriented models with graphical interfaces.

### 🎮 Tetris Application
- Development of a Tetris-inspired application in C#.
- Object-oriented representation of game pieces and the playing field.
- Implementation of piece movement and collision handling.
- Use of factories to create different types of pieces.
- Graphical visualization using Windows Forms.

## 🚀 Getting Started

**Requirements:**
- Visual Studio with .NET desktop development support
- A compatible .NET SDK

To explore the projects:

1. Clone the repository.
2. Open the desired project folder.
3. Open the `.sln` solution or `.csproj` project file in Visual Studio.
4. Build and run the application.

Each TD/TP can be explored independently, depending on its project structure.
